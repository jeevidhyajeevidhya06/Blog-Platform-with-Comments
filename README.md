# Blog Platform with Comments

## Run
1. Extract the ZIP.
2. Install Node.js 18 or later.
3. Open this folder in File Explorer, type `cmd` in the address bar, and press Enter.
4. Run `npm install`
5. Run `npm start`
6. Open http://localhost:3000

SQLite database is created automatically as `blog.db`.

Features: register/login, JWT authentication, create/read/edit/delete posts, add comments, REST API, SQLite database.
